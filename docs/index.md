# CK3 AI Assistant Documentation

Welcome to the CK3 AI Assistant documentation. This comprehensive guide will help you understand, install, and use the AI Assistant effectively.

## Overview

CK3 AI Assistant is an intelligent system featuring dual AI personalities (Emily and Daemon) working together to provide comprehensive solutions for gaming, particularly focused on Crusader Kings III integration.

## System Requirements

- Python 3.10 or higher
- Working microphone and speakers
- 4GB RAM minimum
- 500MB free disk space
- Graphics card supporting OpenCV
